## 走过的路

+ 一六年暑，于学校机房，第一次以随笔的形式在[博客园](//www.cnblogs.com)留下足迹。
+ 一八年冬，备案号获批，旅居之人开始踏上归途。之前的日子里，由海外至境内、从虚拟主机到云服务器，[景安](//www.zzidc.com)、[阿里](//www.aliyun.com)等先后见证了我用[WordPress](https://cn.wordpress.org/)建站的磕磕绊绊。钟情于[Hestia](https://cn.wordpress.org/themes/hestia/)主题，在往后的几年中，曾耗费大量精力反复调整其外观，也为改善响应速度做出过诸多尝试。然而，WP的局限性远不止于此。
+ 二一年秋，忍痛做割舍，将旧站打包封存。相比于WordPress，[Typecho](https://typecho.org/)肉眼可见的简洁、轻量，不必为等待抓狂；[handsome](https://www.ihewro.com/archives/489/)主题给我的感觉则是精致、强大，但使用者过多，难免会有视觉疲劳。
+ 二三年春，再逢岔路口，服务器的剩余时间已不足三月。删删改改后，看着剩下的寥寥几篇文章，萌生了静态托管的想法。最终在[银河渡舟](//suborbit.net)的推荐下，拥抱新兴的[Astro](https://docs.astro.build/zh-cn/concepts/why-astro/)。

## 新的里程

### 框架选择

相较于Hexo等框架，Astro当初在国内并没有广泛的用户基础，可供选择的主题极少，但也有着如下几处优势：

+ 速度可观：这往往是重中之重。
+ 部署方便：有众多托管方案可以选择。
+ 内容优先：对于MarkDown的支持很不错。
+ 开发友好：文档详实、集成广泛……也许会有无限可能！

所以，我似乎可以亲手在这里打造出一片独一无二的数字花园。

### 开源主体

自落地之初，[reashal](//www.reashal.com)便根植于广阔的开源生态；经多年迭代，已然吸收了许多优秀的设计思路，并将坚定地做好下一棒接力。

所以，承蒙相助，愿再偕行。

- 应用场景：或许是过了昂扬的年纪、或许是少了文字的共鸣，不知从何时起，写作对我来说变得愈发吃力。以碎片化的记录汇聚时光的川流，可能已经迫在眉睫。所以主题在设计时，更加侧重于『动态』板块，兼顾『随笔』需求。
- 背景图片：取自『WallPaper-李擎洲-小梨花』。
- 主题字体：采用『HarmonyOS Sans』。
- 评论系统：采用『Giscus』。
- 托管镜像：采用『EdgeOne』、『Netlify』、『Vercel』与『CloudFlare』。

### 浅谈几笔

至此，这个静态主题几乎已经囊括了现阶段我所能想到的、它能够做到的任何需求，除了在编辑内容时，只能通过电脑操作分支，然后等待网络畅通……

所以，一个「Git-based Headless CMS」程序应运而生——

| 分类 | 特征 |
| --- | --- |
| CMS 核心特征 | 提供动态、随笔、展示和图片的可视化管理 |
| CMS 核心特征 | 支持草稿、校验、预览、发布和版本记录 |
| CMS 核心特征 | 非技术用户无需直接编辑 Markdown、JSON 或 Git |
| 无头特征 | Studio 只管理内容，不负责最终网站渲染 |
| 无头特征 | 内容保存在 Git 仓库，由 Astro 主题读取并生成前端页面 |
| 无头特征 | 内容模型与展示层基本分离，可以更换主题或构建流程 |
| 与传统无头 CMS 的区别 | 不依赖数据库，也不提供面向消费者的公共 Content API |
| 内容存储方式 | Git 仓库既是内容数据库，也是版本历史 |

**看到这里，您可能会有如下几个问题：**

- 为什么要开发这个CMS？
    - 为了追求更好的创作体验，如跨设备同步、可视化操作、Git加速、内容分离等。
- 为什么不选择其它工具？
    - 为了更自然地与前端适配、为了验证一些想法落地、为了避免all in one……
- 我该如何使用这个程序？
    - 由于它能直接操作git仓库，所以出于数据安全和维护精力的顾虑，暂时不能与大家见面。
- 那为什么还要提到这些？
    - 或许能为您唤起一丝灵感。
- 所以我是谁？
    - 一名全栈开发者，尤其偏科.NET。

### 未来展望

文章在不同的阶段阅读时，总会有不同的感触。每次迁移，也总会作出相应删减——

- 学习记录：曾经一步一坑、磕磕绊绊的学习记录，回头看，轻舟已过万重山。年久则不必留念，互联网能将它们记住多久，便存在多久，不再迁移备份。
- 生活随笔：没有营养的废话一并删除，不便公开的文章备份吃灰，只留下人生各个阶段最为有力的内心写照。如果愿意，您且听我细说。
